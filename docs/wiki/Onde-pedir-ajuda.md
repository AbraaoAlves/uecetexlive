# Onde pedir ajuda

> **Para quem é:** qualquer pessoa travada em algo no UeceTexLive, no modelo
> uecetex2 ou na classe abnTeX2.
> **Você vai concluir:** saber qual canal usar para não esperar resposta no
> lugar errado.

**Antes de começar:** nada.

## Passos

1. Identifique de qual camada é a sua dúvida:
   - **O app em si** (UeceTexLive) não abre, trava ou se comporta de forma
     inesperada → canais deste projeto.
   - **Estrutura/normas específicas da UECE** (o modelo uecetex2) → projeto
     uecetex2.
   - **Classe, citação ou estilo bibliográfico do abnTeX2** → projeto
     abnTeX2.
   - **LaTeX em geral**, fora do escopo do UeceTexLive → comunidade LaTeX.
2. Use a tabela completa de canais em
   [`SUPPORT.md`](https://github.com/AbraaoAlves/uecetexlive/blob/main/SUPPORT.md).
3. Se for um **bug reproduzível**, abra uma issue com o template "Relatar um
   problema" e inclua o modo de compilação (Rascunho/Completa) e o conteúdo
   do painel **Detalhes**, se houver.
4. Se for uma **vulnerabilidade ou risco de perda de dados**, não abra uma
   issue pública — siga o fluxo privado descrito em
   [`SECURITY.md`](https://github.com/AbraaoAlves/uecetexlive/blob/main/SECURITY.md).

## Resultado esperado

Sua dúvida chega ao canal certo na primeira tentativa.

## Se algo der errado

- **Não tenho certeza de qual camada é o problema.** Abra uma issue no
  UeceTexLive mesmo assim — ajudamos a redirecionar.
- **As Discussions não estão disponíveis.** Ainda não foram habilitadas
  neste repositório; enquanto isso, use uma issue normal para dúvidas de
  uso.
