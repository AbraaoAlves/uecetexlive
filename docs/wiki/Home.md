## O que é o UeceTexLive

Uma aplicação 100% estática — sem backend, sem conta, sem compilação em
servidor — que carrega o modelo uecetex2 (estrutura ABNT para a UECE) e
compila para PDF via WebAssembly, direto no navegador. Iniciativa
extraoficial, sem vínculo institucional com a UECE.

Mais contexto técnico: [`README.md`](https://github.com/AbraaoAlves/uecetexlive/blob/main/README.md)
do repositório principal.
