# Onde pedir ajuda

O UeceTexLive é um projeto extraoficial. Para não capturar problemas que
pertencem a outros projetos, cada tipo de dúvida tem um canal principal:

| Assunto | Canal |
| --- | --- |
| Dúvida de uso do UeceTexLive | [GitHub Discussions, categoria "Q&A" (Ajuda)](https://github.com/AbraaoAlves/uecetexlive/discussions/categories/q-a) |
| Experiência de uso, ideia ou feedback | [GitHub Discussions, categoria "Ideas"](https://github.com/AbraaoAlves/uecetexlive/discussions/categories/ideas) |
| Bug reproduzível no app | [Issue com o template "Relatar um problema"](https://github.com/AbraaoAlves/uecetexlive/issues/new?template=bug.yml) |
| Erro ou lacuna nesta documentação | [Issue com o template "Relatar problema de documentação"](https://github.com/AbraaoAlves/uecetexlive/issues/new?template=documentacao.yml) |
| Regra ou modelo específico da UECE | [uecetex2 (upstream)](https://github.com/thiagodnf/uecetex2/issues) — com link e evidência do que você observou |
| Classe, citação ou estilo bibliográfico do abnTeX2 | [abnTeX2](https://github.com/abntex/abntex2/issues) |
| LaTeX em geral (fora do escopo do UeceTexLive) | [TeX StackExchange](https://tex.stackexchange.com/) (inglês); para dúvidas gerais de programação em português, [Stack Overflow em Português](https://pt.stackoverflow.com/) |
| Vulnerabilidade ou perda de dados | fluxo privado descrito em [`SECURITY.md`](SECURITY.md) |

## Antes de perguntar

1. Confira a [Wiki](https://github.com/AbraaoAlves/uecetexlive/wiki) — a
   seção "Ajuda" da barra lateral reúne solução de problemas, perguntas
   frequentes e limitações conhecidas (algumas páginas ainda em elaboração;
   ver [Limitações conhecidas](https://github.com/AbraaoAlves/uecetexlive/wiki/Limitacoes-conhecidas)
   para o que já está documentado).
2. Indique o **modo de compilação** (Rascunho ou Completa) e, se houver, o
   conteúdo do painel **Detalhes**.
3. Diga se o problema é do **UeceTexLive** (o app), do **modelo uecetex2**
   (estrutura/normas UECE) ou da **classe abnTeX2** (LaTeX/bibliografia) —
   isso ajuda a rotear para o canal certo. Se não tiver certeza, comece pela
   categoria [Q&A](https://github.com/AbraaoAlves/uecetexlive/discussions/categories/q-a);
   nós ajudamos a redirecionar.
